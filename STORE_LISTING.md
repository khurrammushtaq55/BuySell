# Hafeez Center Device Buy/Sell Tracker - Store Listing & Release Notes

## App Short Description
Device Buy/Sell register, Stock management, Khata & Udhaar tracker for mobile shops.

## App Full Description
Hafeez Center Tracker replaces paper register notebooks for mobile, laptop, and electronics shops. Record purchases, sales, customer udhaar, supplier payouts, and automatically calculate profit and loss on device.

Key Features:
- 10 Preset Categories: Mobile, Tablet, Laptop, Console, Smartwatch, Accessories, Parts, etc.
- Step-by-Step Lay-User Design: Designed for shopkeepers with plain language (Khareedari, Farokht, Khata).
- Offline-First Architecture: Record transactions offline with Room DB and sync automatically when connected.
- Receipt Generation: PDF receipts with shop logo, IMEI numbers, and one-tap WhatsApp sharing.
- Multi-Locale Support: 8 UI locales including English, Urdu, Spanish, French, Hindi, Arabic, Chinese.
